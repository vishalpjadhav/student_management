# 🎓 EduCore - College Management System

EduCore is a lightweight, fast, and easy-to-use web portal designed for colleges to manage student rosters, track daily attendance, schedule timetables, and assign tasks. 

Built with **Python (Flask)** and optimized to run efficiently on free cloud hosting tiers using a direct text-based file database setup.

🔗 **Live Project Link:** [https://educore-system.onrender.com](https://educore-system.onrender.com)

---

## ✨ Features

### 👔 Faculty & Admin Portal
* **Easy Registration:** Faculty members can create their own custom accounts using their Employee ID.
* **Master Control Panel:** Access to add, view, or remove student profiles and faculty records.
* **Interactive Attendance Sheet:** A clean visual calendar grid where teachers can mark students present/absent with automatic percentage calculations.
* **Manage Schedule & Tasks:** Create or update the institutional class timetable and assign homework tasks with deadlines.

### 👥 Student Portal
* **Secure Login:** Students log in using their unique Roll Number and password.
* **Read-Only Security:** Students can view information but are restricted from altering any data or marking attendance.
* **Personal Dashboard:** Students can update their profile picture and see a live tracking statement of their monthly attendance performance.
* **Stay Updated:** Easy tracking view of up-to-date class schedules and assigned homework tasks.

---

## 🛠️ Technology Stack

* **Backend Engine:** Python 3.11 & Flask Framework
* **Data Storage:** Optimized Native CSV File Database (Zero-Memory Overhead)
* **Frontend UI:** HTML5, CSS3 (Bootstrap 5), and JavaScript (jQuery Async Operations)
* **Hosting Platform:** Render (Using Persistent Disk Storage to prevent data loss)-
